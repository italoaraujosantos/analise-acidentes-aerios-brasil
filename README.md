# Análise de Acidentes e Incidentes Aérios no Brasil

Análise de dados Acidentes ocorridos a partir do ano de 2007  até Maio de 2026 em solo brasileiro. Conjuntos de dados obtidos a partir do sitio <https://dados.gov.br/dados/conjuntos-dados/ocorrencias-aeronauticas-da-aviacao-civil-brasileira>. 

O conjuntos de dados são do CENIPA - Centro de Investigação e Precenção de Acidente Aérios, orgão central do SIPAR - Sistema de Investigações de Acidentes e Prevenção de Acidentes Aeronáuticos:

* Ocorrencias.csv
* TipoOcorrencia.csv
* Aeronave.csv
* FatorContribuinte.csv
* Recomendacao.csv

Suas atividades são regidas pelo Decreto nº 5.196/2004 e fundamentadas no Anexo 13 da Convenção Internacional de Aviação Civil da ICAO, que é o documento internacional que define os padrões e práticas recomendadas para investigação de acidentes aeronáuticos em todos os países signatários da convenção.
